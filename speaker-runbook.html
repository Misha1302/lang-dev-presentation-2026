1:00 · Engineering tension: independent owners, concrete execution

Open to extension. Concrete at execution.

02
1:20 · Why features require contributions across compiler stages

A feature cuts across the whole compiler

A language feature is a vertical slice: syntax, AST, lowering and execution all participate.

So ownership should move from the central compiler into feature modules.

03
1:20 · Ownership moves from central edits to selected modules

Make the extension points module-owned

Each module owns its contributions. A dialect only selects which modules form the language.

Now we can build a genuinely restricted language from the same compiler.

04
1:30 · A real selection defines the allowed language surface

The selected modules are the language

These selected modules literally define the language surface: arithmetic is present; loops and interop are not.

Caveat: Restricted composition is not a hardened security sandbox.

But selecting modules is not enough — global choices still have to be resolved.
