# EVIDENCE_BOUNDARIES — LangDev presentation rebuild 2026-09-17

## Status labels

- IMPLEMENTED NOW: only for claims directly supported by current code/tests/docs.
- IMPLEMENTED WITNESS: bounded working implementation supports part of the architecture argument.
- PARTIAL WITNESS: evidence exists, but not the full general claim.
- GENERAL ARCHITECTURE: design-level responsibility boundary.
- RESEARCH HYPOTHESIS: falsifiable claim not proved by current implementation.
- THOUGHT EXPERIMENT / TARGET: illustrative target path, not a current implementation claim.
- PRIOR ART: established external mechanism or related approach.

## Main deck claims

- `Delegates` as a cross-type-system language feature is a TARGET / RESEARCH HYPOTHESIS.
- Direct-call delegate erasure is a THOUGHT EXPERIMENT / TARGET unless a current implementation proves the specific rewrite.
- UniversalToolchain is an IMPLEMENTED/PARTIAL WITNESS for selected planning, route feasibility and local deabstraction ideas only.
- Structural resolution means coherent assembly of a concrete compiler configuration; it does not imply semantic preservation.
- Unsupported, unknown, refuted or contradictory evidence must fail closed for transformations that require proof.

## Explicit non-claims

- No claim that one contract models every conceivable type system.
- No claim that extensible programming has zero runtime or zero authoring cost.
- No invented performance numbers.
- No novelty claim for language composition, modular typing, global plans, proof obligations, analysis invalidation, MLIR interfaces/effects/conversion, or translation validation individually.
